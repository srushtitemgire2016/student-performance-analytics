# Student Performance Analytics System

## Project Overview
This project analyzes student marks using Python, Pandas, and NumPy. It calculates student totals, averages, grades, and pass/fail results.

## Features
- Student marks table
- Total and average marks calculation
- Grade assignment
- Pass/fail analysis
- Class average and topper identification
- Subject-wise average analysis
- Top three student ranking
- Bar chart of student averages
- CSV report export

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## How to Run
Run the following command in the terminal:

`python main.py`

If your system uses a different Python command, use the Python 3.11 executable configured for this project.

## Output Files
- `student_performance_report.csv` — student analysis report
