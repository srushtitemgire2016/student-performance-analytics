# Student Performance Analytics System

## Project Overview
This project analyzes student marks using Python, Pandas, and NumPy. It calculates student totals, averages, grades, and pass/fail results.

## Features
- Student marks table
- Total and average marks calculation
- Grade assignment
- Pass/fail analysis
- Class average and topper identification
- Subject-wise average analysis
- Top three student ranking
- Bar chart of student averages
- CSV report export

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## How to Run

### Prerequisites
- Python 3.11
- Pandas
- NumPy
- Matplotlib

### Steps

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the required libraries if they are not already installed:

   ```powershell
   python -m pip install pandas numpy matplotlib
   ```

4. Run the project from the folder containing `main.py` and `student.csv`:

   ```powershell
   python main.py
   ```

5. View the student performance analysis in the terminal and the bar chart in the chart window.

The program generates `student_performance_report.csv` containing the analyzed student data.

## Output Files
- `student_performance_report.csv` — student analysis report
